## Week 2: Development Environment and First Java Program

### Objective
To configure the Java development environment, write a simple Java program, compile it, execute it and submit the source code through GitHub.

### Tools Used
- Java Development Kit (JDK)
- Visual Studio Code
- Git
- GitHub Desktop
- GitHub

### Files
- `week02/HelloWorld.java` — First Java program

### How to Run
1. Open a terminal in the `week02` directory.
2. Compile the program: javac HelloWorld.java
3. Run the program: java HelloWorld

## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables
- Use appropriate primitive and reference data types
- Perform arithmetic calculations
- Read keyboard input using Scanner
- Display formatted output
- Compile, test and submit Java programs using GitHub

### Programs
1. `week03/SimpleCalculator.java`  
Performs arithmetic calculations (sum, difference, product, quotient) on two numbers.

2. `week03/AverageCalculator.java`  
Calculates the total and average of three scores and displays the student result.

3. `week03/ItemCost.java`  
Calculates the total cost of an item using quantity and unit price.

### How to Run
Open a terminal in the `week03` directory and run the following commands:

**Simple Calculator**
javac SimpleCalculator.java
java SimpleCalculator


**Average Calculator**
javac AverageCalculator.java
java AverageCalculatortext


**Item Cost**
javac ItemCost.java
java ItemCost


### Testing
Each program was tested with different valid inputs to confirm correct calculations and formatted output.
